# 财务数据提取工具 v2.0

## 功能说明

本工具用于从PDF财务报告中自动提取母公司报表和合并报表数据，并生成对照表。

### 主要功能（共6张报表）：

1. **识别并读取财务报告** - 支持从指定目录或文件选择器读取PDF格式的财务报告
2. **提取6张报表**：
   - 母公司资产负债表
   - 合并资产负债表
   - 母公司现金流量表
   - 合并现金流量表
   - 母公司利润表
   - 合并利润表
3. **单独显示报表** - 每个报表类型单独一个Tab页展示
4. **汇总对照表** - 同一报表类型下，母公司对应合并报表，并计算差值
5. **原始数据查看** - 可查看从PDF中提取的每个表格的原始数据
6. **导出Excel** - 支持将所有数据导出为Excel文件

## 安装步骤

1. 确保已安装Python 3.8或更高版本

2. 安装依赖包：
   ```bash
   pip install -r requirements.txt
   ```

3. 将财务报告PDF文件放入 `data` 目录

## 使用方法

1. 运行程序：
   ```bash
   python run.py
   ```

2. 在GUI界面中：
   - 点击"📂 选择PDF文件"按钮选择财务报告PDF
   - 或者直接在左侧文件列表中点击文件名
   - 点击"📊 提取数据"按钮提取数据
   - 通过Tab切换查看各个报表
   - 在"汇总对照表"中查看母公司与合并报表的对照及差值
   - 点击"💾 导出Excel"导出数据

## 界面说明（共8个Tab）

| Tab | 说明 |
|-----|------|
| 母公司资产负债表 | 单独显示母公司资产负债表 |
| 合并资产负债表 | 单独显示合并资产负债表 |
| 母公司现金流量表 | 单独显示母公司现金流量表 |
| 合并现金流量表 | 单独显示合并现金流量表 |
| 母公司利润表 | 单独显示母公司利润表 |

## 注意事项

- PDF文件需要包含标准的财务报表格式
- 程序会自动识别关键字来区分报表类型和公司类型
- 报表类型识别关键词：
  - 资产负债表：资产总计、负债和所有者权益
  - 现金流量表：经营活动产生的现金流量、现金流出
  - 利润表：营业收入、净利润、利润总额
- 公司类型识别关键词：
  - 母公司：母公司
  - 合并报表：合并
